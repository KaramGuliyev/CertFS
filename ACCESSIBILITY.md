# Accessibility

CertFS Quiz aims to be usable by everyone who uses Obsidian.

## What we do

- All UI is built from Obsidian's own components (modals, settings, buttons, checkboxes), so it follows your theme, font size and contrast settings, and works with Obsidian's keyboard navigation.
- Colors come from Obsidian theme variables; right/wrong results are shown with text (✅ / ❌ and the correct answer), not by color alone.
- Every action is available as a command (Ctrl/Cmd+P), so the plugin can be used without the mouse and with custom hotkeys.
- Works on desktop and mobile.

## Supported environments

- Obsidian 1.4.10 or newer, on Windows, macOS, Linux, iOS and Android.

## Known limitations

- Quiz questions are generated by an AI model; wording can sometimes be long or unclear. Use **Hint** or **Not sure** and the explanation shown after each answer.
- Screen reader support depends on Obsidian itself; the plugin has not been formally tested with screen readers yet.
- Emoji are used in labels and notes; some screen readers read them aloud.

## Report a barrier

Open an issue with the **Accessibility barrier** template: describe what you tried, what got in the way, your platform and any assistive technology you use.
